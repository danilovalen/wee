# Additions for the danilo-copywriting skill (registers 510, 511)

The skill lives on your machine and an agent here cannot edit it. Paste these under **STATED**.

**Plain, common verbs, used with an object.** (2026-10-30: *"Too weird wording, intransitive,
uncommon verbs should be avoided."*) Write "A block or a wall stops the robot", not "the robot
stops"; "Run moves the robot for you", not "then it plays". A rare verb ("steer") or a verb with no
object makes the reader work out who does what.

**An objective is an order, never a fact.** (2026-10-30: *"It is not reaching the star. The objective
is having the robot reaching the star."*) "Robot reaches the star" reads as something already
happening. Write what the player must make happen: "Get the robot to the star", "Push a box into
another box", "Leave every switch off at the end". This is the STATED command rule applied to goal
lists, which are where it gets forgotten: a list of goals reads like a description, so it drifts
into the third person.
