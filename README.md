# wee

A Mario Maker style sandbox for an ice-slide puzzle game. Build a room, play it on the same
screen, and switch player powers on and off.

    npm install
    npm start        # http://localhost:5173
    npm test

Keys in play: arrows slide, Space jumps, R returns you to the checkpoint, E switches between
editing and playing. `rooms/sample.wee` is a room with every piece in it; open it with Open.
